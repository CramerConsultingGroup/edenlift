🔌 API Documentation

Integrate Eden Lift Into Your Applications

Overview

The Eden Lift API provides programmatic access to our platform's core functionality. Build integrations, automate workflows, and create custom applications on top of our infrastructure.

Quick Start

🔑 Authentication

Secure API key-based authentication with optional OAuth2 support.

📡 RESTful Design

Standard REST endpoints with JSON request/response format.

📊 Rate Limits

Generous rate limits with webhook support for real-time updates.

🛠 SDKs Available

Client libraries for Python, JavaScript, Java, and more.

Base URL

https://api.edenlift.org/v1

Authentication

All API requests require authentication using an API key passed in the Authorization header:

Authorization: Bearer YOUR_API_KEY

API Endpoints

Projects

  • GET /projects - List all projects
  • GET /projects/{id} - Get project details
  • POST /projects - Create a new project
  • PUT /projects/{id} - Update project
  • DELETE /projects/{id} - Delete project

Investments

  • GET /investments - List investments
  • GET /investments/{id} - Get investment details
  • POST /investments - Create investment
  • GET /investments/{id}/analytics - Get investment analytics

Documents

  • GET /documents - List documents
  • POST /documents - Upload document
  • GET /documents/{id} - Get document details
  • POST /documents/{id}/sign - Sign document
  • GET /documents/{id}/verify - Verify signature

Analytics

  • GET /analytics/impact - Get impact metrics
  • GET /analytics/financial - Get financial data
  • GET /analytics/trends - Get trend analysis

Example Request

curl -X GET "https://api.edenlift.org/v1/projects" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"

Response Format

All API responses follow this standard format:

{
  "success": true,
  "data": { ... },
  "message": "Success",
  "timestamp": "2025-11-03T23:17:20Z"
}

Error Handling

Error responses include standard HTTP status codes and detailed error messages:

  • 400 - Bad Request
  • 401 - Unauthorized
  • 403 - Forbidden
  • 404 - Not Found
  • 429 - Rate Limit Exceeded
  • 500 - Internal Server Error

SDKs & Libraries

Official client libraries are available:

  • Python: pip install edenlift-sdk
  • JavaScript/Node.js: npm install edenlift-sdk
  • Java: Maven/Gradle dependencies available
  • Go: go get github.com/edenlift/go-sdk
